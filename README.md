## Featured Projects

### Email Agent
AI-powered email intelligence system that reads a Gmail inbox, classifies and scores messages, and surfaces what actually needs attention.

**Stack**

- Backend: Python, FastAPI, Gmail API
- AI layer: Gemini, OpenAI, Ollama (local LLM)
- Database: SQLite (MVP), PostgreSQL (production)
- Frontend: React, TypeScript, Tailwind CSS

**Features**

- *Email intelligence* — Gmail API integration with read-only access, email classification, importance scoring, urgency detection, opportunity detection
- *AI-powered analysis* — email summarization, action-required detection, deadline extraction, meeting extraction, suggested reply generation
- *Productivity* — important inbox view, daily priority digest, opportunity tracking, reminder generation
- *Security* — read-only Gmail permissions, no automatic sending, no inbox modifications, all actions user-controlled

### [Neuro RAG — MRI Intelligence](https://github.com/vinonachi/NeuroRAG_MRI)
Retrieval-augmented generation system for neuroimaging workflows, combining semantic search with clinical MRI context to answer queries directly over scan reports.

**Stack:** Python, RAG, vector embeddings, LLMs

- Semantic retrieval layer grounded in clinical MRI documentation
- LLM-based response generation for context-aware, explainable answers
- Built for document-heavy clinical workflows where keyword search falls short
